# Candidate 1,000-item question bank

`question_bank_1000.json` was synchronized from the `Kong19565` branch as a research and future adaptive-assessment input.

- The running interview still uses `questions.json`; this file is not imported by the live app.
- The source labels in the JSON identify the framework each item was drafted from, but they do not by themselves establish that every Thai item is a validated psychometric measure.
- Review content validity, language, branching behavior, fairness, and scoring before connecting this bank to the assessment flow.

This separation preserves the new research data without presenting it as a deployed or validated questionnaire.
