>
> FutureMe AI คือผู้ช่วยสำรวจเส้นทางเรียนและอาชีพสำหรับเด็กไทย ระบบไม่ได้ให้คำตอบเดียว แต่ชวนคุย ให้ลองทำภารกิจสั้น ๆ แล้วเสนอสามเส้นทางคู่ขนาน พร้อมเหตุผล หลักฐาน สิ่งที่ยังไม่รู้ และก้าวเล็ก ๆ ที่ลองทำได้ภายใน 30 วัน”

## Q&A

### ระบบใหญ่เกินไปหรือไม่

เริ่มจาก vertical slice ที่ทำงานได้โดยไม่พึ่งระบบภายนอก: guest interview → mission หนึ่งแบบ → สามเส้นทาง → roadmap → แผน 30 วัน จากนั้นค่อยเพิ่ม corpus, dashboard และ integration ตามหลักฐานจากผู้ใช้

### ถ้า AI แนะนำผิดหรือ hallucinate จะทำอย่างไร

ใช้กฎคุม hard constraints แยก evidence index จาก design/pitch index บังคับ citation และ refusal เมื่อค้นหลักฐานไม่พอ ทุก route ต้องแสดง uncertainty และให้เด็กแก้ profile หรือคุยกับคนจริงได้ แนวทางนี้ยังต้องมี test suite และ independent evaluation set ก่อน pilot

### ใช้ RIASEC แล้วจะกลายเป็นการตีตราเด็กหรือไม่

RIASEC ต้องเป็นเวกเตอร์ความสนใจหลายมิติ ไม่ใช่ประเภทบุคคลแบบตายตัว แบบคำถามและ mission rubric ของ FutureMe ยังไม่ผ่าน psychometric validation จึงใช้เพื่อการสำรวจเท่านั้น

### ข้อมูลเด็กปลอดภัยอย่างไร

ออกแบบให้เก็บข้อมูลเท่าที่จำเป็น raw transcript เป็นข้อมูลส่วนตัวโดยค่าเริ่มต้น การแชร์ต้องมี policy, สิทธิ์, audit trail และทางถอน consent การเลือก cloud ในไทยอย่างเดียวไม่ทำให้ระบบผ่าน PDPA โดยอัตโนมัติ

### เชื่อม NDLP/DEEP หรือ AIS แล้วหรือยัง

ยังไม่เชื่อม เอกสารปัจจุบันเป็น target integration เท่านั้น ต้องมี official API documentation, credential, technical access, licensing และข้อตกลงก่อน

### AIS Cloud ทำให้ข้อมูลอยู่ไทย 100% หรือไม่

ยืนยันแบบเหมารวมไม่ได้ ต้องตรวจบริการ region เส้นทางข้อมูลภายนอก LLM provider สัญญา backup และ log ของ deployment จริง การใช้ AIS Cloud เป็น target ไม่ใช่หลักฐาน data sovereignty หรือ PDPA compliance

### ผลลัพธ์ที่คาดว่าจะวัดคืออะไร

เอกสารตั้งเป้า clarity เพิ่ม 1.5 คะแนนและผู้เรียน 90% เห็นอย่างน้อยสามเส้นทาง ตัวเลขเหล่านี้เป็น target จนกว่าจะกำหนด scale, baseline, sampling และวัดผล pilot จริง
